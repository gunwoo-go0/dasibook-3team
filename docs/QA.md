QA-19는 판매중이라는 답은 맞았지만 묻지 않은 정산 안내를 틀리게 덧붙였고, QA-20은 앞 질문의 '파이썬 입문'을 끌어와 팔린 책이 없다고 답했고, QA-24는 앱이 넣은 표시 문구를 답에 그대로 내보냈다. 화면: [QA-19](images/qa/fix-6-pc1-QA-19.png), [QA-20](images/qa/fix-6-pc1-QA-20.png), [QA-21](images/qa/fix-6-pc1-QA-21.png), [QA-22](images/qa/fix-6-pc1-QA-22.png), [QA-24](images/qa/fix-6-pc1-QA-24.png)
  2. 2차 수정(1a19d5f): 도서를 찾은 질문은 앞 대화 없이 '앱이 찾은 도서 + 질문'만 보내고, 규칙 질문(도서 ID·위탁자 ID·도서명이 없는 질문)은 도서 목록 없이 수업 예제처럼 '최근 대화 + 질문'만 보낸다. 지시문에 묻지 않은 정산·메뉴 이야기를 덧붙이지 않기, 처리 요청에는 해당 메뉴 이름을 알려 주기를 더했다. 질문 5개를 한 대화에서 차례로 물었을 때 앱이 모델에 이렇게 보내는 것을 확인했다.
- 남은 한계: Qwen3.5 2B는 작은 모델이라 같은 질문에도 답 문장이 조금씩 다르고, 찾은 도서와 다르게 말할 때가 있다. 그래서 찾은 도서는 앱이 표로 직접 보여 주고 직원은 그 표를 기준으로 확인한다. 2차 수정 뒤 실제 모델 답변은 따로 기록하지 않았다.

### 그 밖에 찾은 것 (선택)

- 입력칸 이름에 역슬래시가 섞인다. 필수 표시 `*`를 `\*`로 적어서, 화면 낭독기가 '도서 ID 역슬래시 별'처럼 읽는다. 화면에 보이는 글자는 정상이다. 같은 화면이라 수정사항 5를 고칠 때 함께 고쳤다(`fix(#5)`).
- 서버를 새로 켠 뒤 첫 접속이 도서 검색이 아닌 화면 주소(예: `/register`)이면 사이드바 메뉴가 파일 이름(app, register 등)으로 보일 수 있다. `streamlit run app.py`로 켜면 첫 화면(도서 검색)이 열리므로 평소에는 생기지 않고, 그럴 때는 서버를 다시 켜고 첫 화면부터 열면 된다. 이번 범위에서는 고치지 않았다.
