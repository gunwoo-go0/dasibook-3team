# Draft: 주요 화면·기능 초안 점검

- 점검 날짜: 2026-11-13 / 커밋: 커밋 전 검토본 (`dasibook` 초안)
- 기준은 제안서의 IA, 화면설계서, 요구사항 대응표다. 초안을 직접 실행해 확인했고, 자세한 시험 결과는 [QA.md](QA.md)에 있다.
- 실행 환경: Python 3.11, Streamlit 1.51.0, pandas 2.3.3 (`requirements.txt`와 같음). 수업 예제 Qwen_Chatbot_2026_Lab의 구조(app.py, llm.py, smoke_test.py, support/)를 그대로 두고 화면과 업무 로직을 더했다.
- AI 검색 도우미는 이 작업 공간에서 대체 Ollama 서버로 연결과 오류 처리를 확인했고, 강건우 PC(Windows)에서 실제 Qwen3.5 2B로 smoke_test.py와 QA-19~22를 확인했다.

## 1. 화면별 구현 상태

| 화면 | 기준 (화면설계서) | 구현 상태 | 메모 |
| --- | --- | --- | --- |
| SCR-01 위탁 도서 등록 | 입력 5개, 판매 상태는 판매중 고정, 처리 순서 필수값 → 가격 → 수수료율 → ID 중복 → 저장 | 구현 | 필수 항목 * 표시, 판매 상태는 읽기 전용 '판매중'. 메시지 5개는 화면설계서 문구 그대로이고, 성공 메시지에 도서 ID를 붙인다("등록이 완료되었습니다. (B013)"). 실패하면 입력값을 그대로 둔다. 판매 가격 소수 입력 문제는 수정사항 5 |
| SCR-02 도서 검색 | 검색 기준 선택, 검색어, 결과 건수와 표, 판매 상태 색 구분, 안내 메시지 | 구현 | 검색 기준 도서명(기본)·도서 ID·위탁자 ID, 앞뒤 공백 무시, "검색 결과 n건", 표 5항목, 판매중 초록·판매완료 회색, 안내 2개 |
| SCR-02 AI 검색 도우미 (추가) | 질문 입력, 답변, 찾은 도서 표, 대화 초기화, 오류 안내 | 구현 (답변 정확도 부족) | 질문 300자 제한, 찾은 도서는 앱이 직접 표로 보여 줌(최대 10권), 대화 초기화, 실패한 질문은 기록하지 않음. 화면 배치 문제는 수정사항 3·4. 실제 Qwen 답변이 찾은 도서 표와 어긋나는 문제는 수정사항 6 |
| SCR-03 판매 상태 변경 | 판매중 도서만 고르기, 선택 도서 정보, 확인 단계, 성공·오류 메시지 | 구현 | 선택 상자 "B003 · 알고리즘 기초" 형식, 확인 단계 [확인][취소], 확인 중에는 선택 상자와 버튼을 잠근다. 처리 후 표시 문제는 수정사항 1·2 |
| SCR-04 위탁자별 정산 | 위탁자 선택, 정산 내역 표, 판매완료 권수, 총정산액, 안내 메시지 | 구현 | 등록된 위탁자 목록에서 고르고 [정산 조회]. 표 5항목, "판매완료 n권", 총정산액(metric) |

## 4. 빠진 부분, 달라진 부분, 수정할 내용

- 빠진 부분:
  - 윈도우에서 엑셀로 books.csv를 열어 둔 상태의 저장 실패(QA-18)는 파일 잠금으로 흉내 내 확인했다. PC에서 한 번 더 본다.
  - 개발용 저장소는 만들었고(https://github.com/gunwoo-go0/dasibook-3team) 아직 커밋 전이다.
- 달라진 부분 (제안서·화면설계서와 다른 점):
  - ID 형식 오류 문구 2개를 더했다: "도서 ID는 B와 숫자 3자리로 입력해 주세요. (예: B013)", "위탁자 ID는 C와 숫자 3자리로 입력해 주세요. (예: C001)". SF-01에는 형식 검사가 있지만 화면설계서 메시지 목록에는 없었다. 처리 순서는 필수값 → 가격 → 수수료율 → ID 형식 → ID 중복 → 저장이다.
  - 도서 검색을 처음 열었을 때는 "전체 도서 n권", 검색한 뒤에는 "검색 결과 n건"으로 표시한다.
  - 수수료율 칸은 12.5 같은 소수를 그대로 받아 검사에서 막도록 실수 입력칸으로 두었다. 정수 입력칸은 12.5를 12로 잘라 버린다.
  - 위탁자별 정산에서 도서 데이터가 아예 없으면 "등록된 도서가 없습니다."를 보여 준다(화면설계서에 없는 경우).
  - books.csv를 손으로 고치다 수수료율 같은 값이 잘못된 판매완료 도서는 정산에서 빼고 경고를 띄운다(화면설계서에 없는 예외).
  - README 설치 순서를 `py -3.11 -m venv .venv`와 버전 확인으로 바꿨다. PC에서 3.11이 아닌 Python으로 가상환경을 만들었더니 `pip install` 중 pyarrow 빌드 오류가 났다.
- 수정할 내용: QA에서 찾은 수정사항 6건([QA.md](QA.md) 아래쪽). GitHub Issue #1~#6으로 등록했고, `fix/issue-번호` 브랜치에서 고친다.
  1. 판매완료 처리 후 다른 도서가 선택되고, 완료 메시지에 처리한 도서가 없음
  2. 다른 창에서 먼저 처리된 도서의 오류 메시지가 화면 맨 위에 뜸
  3. AI 답변·찾은 도서 표·입력칸이 화면 아래로 밀려 스크롤해야 보임
  4. 검색할 말이 없는 질문에도 '찾은 도서 없음'이 떠서 검색에 실패한 것처럼 보임
  5. 판매 가격에 소수(8000.5)를 넣으면 알림 없이 8000원으로 등록됨
  6. 실제 Qwen 답변이 찾은 도서 표와 반대로 말하거나 앞 대화의 도서를 덧붙임
